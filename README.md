# AlgoPlay ✦

### Python, but you can see it think.

AlgoPlay is a playful, beginner-friendly learning experience that helps learners understand **Bubble Sort** by building the code one line at a time and watching the numbers move.

Instead of only reading code, learners can see comparisons, swaps, and the final sorted result through a simple visual interface.

> **Learn a line. Understand the logic. Watch the algorithm.**

---

## ✨ What is AlgoPlay?

AlgoPlay turns a classic beginner programming concept into a guided, visual experience. It is designed for people who are new to Python and want to understand what an algorithm does—not just copy and paste code.

## 🚀 Features

- **Guided coding steps** — build the Bubble Sort example one line at a time.
- **Hints for each step** — get a nudge when you're stuck.
- **Animated array visualizer** — watch neighboring values being compared and swapped.
- **Live counters** — follow the number of comparisons and swaps.
- **Beginner-friendly explanations** — understand why a comparison or swap happens.
- **Prediction challenge** — test your understanding before revealing the next move.
- **Progress feedback** — get clear feedback as you work through the lesson.
- **Responsive interface** — designed to be usable on desktop and smaller screens.
- **Creator link** — connect with the creator on Instagram.

## 🔎 How Bubble Sort works

Bubble Sort repeatedly compares adjacent values. If the left value is greater than the right value, it swaps them. Each pass moves larger values toward the end of the list. The process repeats until the list is sorted.

Example:

```python
numbers = [5, 1, 4, 2, 8]
print(bubble_sort(numbers))
```

Expected result:

```text
[1, 2, 4, 5, 8]
```
